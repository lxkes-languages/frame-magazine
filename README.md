# FRAME — Independent Visual Journal

An editorial-style, image-led static website for GitHub Pages.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository (e.g. `frame-magazine`).
2. Upload `index.html`, `style.css`, and `script.js` to the **root** of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main**, folder **/(root)**, then **Save**.
6. Wait for deployment and open the Pages URL shown in Settings → Pages (usually `https://USERNAME.github.io/frame-magazine/`).

## Customize

- Edit the site name and headings in `index.html`.
- Replace the Unsplash image URLs with images you own or have permission to use.
- Edit colors, typography, spacing, and layout in `style.css`.
- Add real post pages and links before publishing content; the example story rows are currently visual placeholders.

This is an original template inspired by image-led editorial design, not a copy of any site's copyrighted assets.
