# FRAME Magazine — v2

An original editorial portfolio/magazine built with plain HTML, CSS and JavaScript, ready for GitHub Pages.

## Publish
1. Open your existing `frame-magazine` GitHub repository.
2. Upload **index.html**, **style.css**, **script.js** and **README.md** from this folder to the repository root, replacing the old files. Commit the changes.
3. GitHub Pages will redeploy automatically from `main` / `(root)` if already enabled.
4. Visit https://lxkes-languages.github.io/frame-magazine/ and hard-refresh if you still see the previous design.

## Edit
- Change text, section names and photos in `index.html`.
- Adjust palette and typography in `style.css`.
- Change sample article content in the `articles` object inside `script.js`.
- Replace `hello@example.com` with your email.
- Replace external Unsplash sample images with licensed or original photos for production. Do not reuse another magazine's photography without permission.

## Features
Responsive editorial homepage, mobile menu, scroll reveals, reading progress indicator, hover image zoom, category filters, three sample articles in accessible native dialogs, and reduced-motion support.

No build step or dependencies required. Google Fonts and Unsplash images require an internet connection.
